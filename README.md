## About Me

Builder focused on creating practical, high-impact tools for the Unity ecosystem and beyond. Since joining GitHub in 2015, I've maintained a consistent commitment to solving real problems through clean, functional code.

Specializing in **C++**, **C**, and **C#**, with recent activity centered around Unity3D tooling, patching solutions, Docker environments, and high-DPI desktop utilities. My work is driven by direct implementation — 100% commit-oriented, delivering production-ready solutions that see widespread community adoption.

Active across 12 public repositories in the last 90 days, primarily shipping updates in C# and C++ for Unity-related projects and system-level utilities.
